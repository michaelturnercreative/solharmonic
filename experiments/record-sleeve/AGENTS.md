# Record sleeve working context

This directory is the active focus of the Record sleeve player work. Keep it
independent of the root public website and app-persistent member application.
Use index.html, styles.css and player.js directly; no framework or build is needed.
Preserve the static scenic backgrounds, refined gold/Ocean logo, Cinzel Regular,
and the user's chosen Record sleeve layout. Do not restore discarded design variants.
Audio is local-only; do not describe folder selection as cloud storage or persistence.
Do not commit personal audio files. Run the checks documented in README.md for changes.
